আগের ডিজাইনে ফেরার ফাইল

১) আগে অ্যাপের Settings থেকে ডেটা ব্যাকআপ ডাউনলোড করুন।
২) ZIP ফাইল Extract করুন।
৩) GitHub repository-তে index.html, app.js, style.css এবং sw.js—এই ৪টি ফাইল Replace/Upload করুন।
৪) assets ফোল্ডার, icon ফাইল এবং manifest.webmanifest পরিবর্তন করবেন না।
৫) Commit changes দিন।
৬) GitHub Pages আপডেট হলে Chrome-এ সাইটটি খুলে Refresh করুন, তারপর ইনস্টল করা অ্যাপ বন্ধ করে আবার খুলুন।
