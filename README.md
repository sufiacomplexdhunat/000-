# বাড়ি ভাড়া ম্যানেজার — বাড়িওয়ালার সংস্করণ (Free PWA)

## ফিচার
- একাধিক বাড়ি/ফ্ল্যাট/ইউনিট
- ভাড়াটিয়ার তথ্য সংরক্ষণ
- মাসিক ভাড়া ও জামানত
- ভাড়া, বিদ্যুৎ, গ্যাস, পানি ও অন্যান্য বিল
- পেমেন্ট রেকর্ড ও বকেয়া হিসাব
- হিসাব প্রিন্ট করে PDF
- JSON ব্যাকআপ ও পুনরুদ্ধার
- Android PWA ইনস্টল

## ডেমো অ্যাডমিন লগইন
মোবাইল: `01700000000`
পাসওয়ার্ড: `ChangeMe123!`
প্রথমেই Settings থেকে পাসওয়ার্ড ও মোবাইল পরিবর্তন করুন।

## বিনামূল্যে GitHub Pages-এ প্রকাশ
1. ZIP Extract করুন।
2. GitHub repository-র root-এ সব ফাইল ও `assets` ফোল্ডার upload করুন।
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save।
4. প্রকাশিত GitHub Pages URL Android Chrome-এ খুলে Install app / Add to Home screen নির্বাচন করুন।

## ডেটা ও গোপনীয়তা — গুরুত্বপূর্ণ
- এই সংস্করণে ডেটা শুধুমাত্র ওই ফোন/ব্রাউজারের localStorage-এ সংরক্ষিত হয়।
- GitHub Pages শুধু ওয়েব ফাইল হোস্ট করে; এটি ক্লাউড ডেটাবেস নয়।
- অন্য ফোনে একই ডেটা স্বয়ংক্রিয়ভাবে দেখা যাবে না।
- ব্রাউজারের ডেটা মুছে গেলে তথ্য হারাতে পারেন। Settings থেকে নিয়মিত JSON ব্যাকআপ ডাউনলোড করুন।
- অ্যাডমিন লগইনটি ডিভাইসের সাধারণ প্রবেশ-নিয়ন্ত্রণ; সার্ভার-ভিত্তিক নিরাপত্তা নয়। সংবেদনশীল তথ্যের একমাত্র রেকর্ড হিসেবে ব্যবহার করবেন না।
- এটি বিনামূল্যের পরীক্ষামূলক সংস্করণ, নিরাপত্তা নিরীক্ষিত পেশাদার সিস্টেম নয়।
