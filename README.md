# সুফিয়া কমপ্লেক্স — বাড়ি ভাড়া ম্যানেজার

বিনামূল্যের landlord-only PWA। Android Chrome থেকে ইনস্টল করা যায়।

## লগইন
প্রাথমিক মোবাইল: `01700000000`
প্রাথমিক পাসওয়ার্ড: `ChangeMe123!`
প্রথম লগইনের পর Settings থেকে পাসওয়ার্ড বদলান।

## আপডেটের বৈশিষ্ট্য
- ভাড়াটিয়ার ঠিকানা, NID ও মিটার নম্বর
- ইউনিট/রুম নম্বর
- কেবল বাড়ি ভাড়ার বিল ও আদায়
- A০০১ থেকে স্বয়ংক্রিয় রসিদ নম্বর
- সুফিয়া কমপ্লেক্সের নাম, ঠিকানা ও ফোন নম্বর
- JSON ব্যাকআপ ও রিস্টোর

## ডেটা সংরক্ষণ
অ্যাপ আগের `rent_manager_free_v1` localStorage key ব্যবহার করে, তাই একই ব্রাউজার ও একই সাইটে আগের ডেটা থাকবে। ডেটা শুধু এই ডিভাইসের ব্রাউজারে থাকে; নিয়মিত Settings থেকে ব্যাকআপ ডাউনলোড করুন।

## GitHub Pages আপডেট
ZIP extract করে repository-তে `index.html`, `app.js`, `style.css`, `sw.js` ফাইলগুলো replace করুন। `manifest.webmanifest` ও `assets` ফোল্ডার আগের মতো রাখুন। সব পরিবর্তন commit করার পর Pages আপডেট হতে কিছুক্ষণ সময় দিন।
